National flag SVGs for the Where map's country hover and keyboard focus fills.

Source: [flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3), by Panayiotis Lipiridis, used under the included [MIT license](LICENSE).

Original files are unchanged and renamed from their two-letter country codes to match the map's three-letter codes: `au` → `AUS`, `at` → `AUT`, `ca` → `CAN`, `hr` → `HRV`, `dk` → `DNK`, `it` → `ITA`, `nl` → `NLD`, `no` → `NOR`, `pl` → `POL`, `si` → `SVN`, `es` → `ESP`, `gb` → `GBR`, `us` → `USA`.
